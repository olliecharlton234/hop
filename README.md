# HOP

A map-first social app for organising real-world outings with friends.

| Folder | What it is | How to run |
|---|---|---|
| `mobile/` | **HOP V6**: the native app (React Native + Expo + TypeScript + Expo Router) | See `mobile/README.md`: `npm install`, then `npx expo start`, then scan the QR code with Expo Go |
| `prototype/` | **HOP V5**: the original web prototype. It's the design reference, kept unchanged | Open `prototype/HOP.html` in a browser |

Branches:

- `main` holds V5 as it was committed.
- `v6-native` holds the native migration.
